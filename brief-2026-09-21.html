01 · Home Assistant OS

Home Assistant OS 18.3 — docker reset-storage, Yellow Bluetooth, RPi fixes

What happened: Tag 18.3 published 2026-09-17T15:52:18Z (author sairon) — a maintenance OS release that did not make Friday’s Core 2026.9.3 brief. Standouts from the GitHub notes:

  • Force filesystem sync when unpacking container image layers — cuts corrupt images after a power cut mid-update
  • New ha docker reset-storage schedules a full Docker storage wipe on next reboot; Supervisor / Core / plugins / apps re-download; config and data outside Docker stay
  • Home Assistant Yellow: hardware flow control on mini UART restores Bluetooth after the 18.0 regression
  • Raspberry Pi: HDMI above 1920×1080 and USB-SSD boot on Pi 3 fixed; F2FS enabled on all targets
  • Setup landing page now defaults to port 80 (legacy 8123 redirects); NTP config moved to timesyncd drop-ins with ha time CLI

Why it matters: Power-cut image corruption and Yellow BLE flakiness are real ops pain. Reset-storage is the supported recovery path — needs internet and a reboot. Community threads over the weekend already report 18.3 update failures when release-asset downloads are filtered.
