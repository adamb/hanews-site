Over the weekend Zigbee2MQTT 2.14.3 put 32-bit installs on notice, and Core 2026.11.0b2 landed ahead of Wednesday's expected 2026.11 release. Stable Core is still 2026.10.4. New guide: the best Zigbee hub for Home Assistant.

01 · Zigbee2MQTT

Zigbee2MQTT 2.14.3 deprecates 32-bit platforms

What happened: Zigbee2MQTT 2.14.3 was released on 1 Nov and marks 32-bit platforms as deprecated. Support ends when the minimum Node.js version becomes v24, which happens when Node.js 22 reaches end of life in April 2027. Node.js 24 has no official 32-bit builds, so the linux/386, linux/arm/v6 and linux/arm/v7 Docker images will not be updated any more. Version 2.14.3 adds a heating system mode for Danfoss Ally eTRV0103, power and energy readings for Sinopé TH1500ZB, OTA support for SONOFF SNZT-03P and SNZT-04P, and an action for the Aqara MCCGQ13LM.

Why it matters: If you run Zigbee2MQTT on a Raspberry Pi 1, a Zero or an older 32-bit Raspberry Pi OS install, plan a move to 64-bit OS or hardware before support ends in April 2027.

Primary source
Zigbee2MQTT 2.14.3; issue #33552

02 · Home Assistant (beta)

Core 2026.11.0b2: ZBT-2 over ESPHome serial proxies, Marketplace update fix

What happened: Home Assistant Core 2026.11.0b2 was tagged on 30 Oct and is listed in beta.json, with the final 2026.11 release expected on Wednesday 4 Nov. The beta shows ZBT-2 and ZBT-1 connections via ESPHome serial proxies, updates Marketplace update entities when a repository is refreshed from its page, and prefers cloud custom domains in get_url. It also closes shared modbus connections when Home Assistant stops or restarts, adds Govee light local temperature ranges, and no longer ends a truncated entity ID with an underscore. Library bumps include py-synologydsm-api 2.11.1, midea-local 15.0.0 and arcam-fmj 3.1.1.

Why it matters: The final 2026.11 release is not out yet, so if the listed changes touch your setup, review the b2 notes before Wednesday 4 Nov. Don't run betas on a house you depend on.

Primary source
core 2026.11.0b2; beta.json
