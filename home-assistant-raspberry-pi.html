How to install Home Assistant on a Raspberry Pi

HA News · 28 Oct 2026 · Checked against HAOS 18.4 and Core 2026.10.4

Disclosure: HA News earns a commission from qualifying purchases made through the Amazon links on this page. Prices and stock are on Amazon; we don't quote them here.

This guide walks through how to install Home Assistant on a Raspberry Pi: the hardware to buy, how to write Home Assistant OS to a microSD card with Raspberry Pi Imager, and what to expect on first boot. If you are still deciding on a Raspberry Pi for Home Assistant, the starting facts are these: the Pi 4 and the Pi 5 are the supported boards, 2 GB of RAM is the minimum, and Home Assistant OS (HAOS) is the recommended install type. Version numbers in this article were current as of 28 October 2026: HAOS 18.4 and Core 2026.10.4. The official installation documentation is at home-assistant.io/installation/raspberrypi; this article follows the same path.

The sections below run in order: hardware, the board choice, the image write, first boot, troubleshooting, storage, and the install-type alternatives, with a short FAQ at the end.

What you need

This is the complete hardware list for a Home Assistant OS install:

  • Raspberry Pi 5 or Raspberry Pi 4, with at least 2 GB of RAM. A 4 GB board clears the minimum. (Raspberry Pi 5 4GB on Amazon; Raspberry Pi 4 4GB on Amazon)
  • A proper power supply. Phone chargers may not deliver full power, and computer USB ports must not be used. (official Raspberry Pi 27W USB-C power supply on Amazon)
  • A microSD card, at least 32 GB, ideally with the Application Class 2 (A2) label. A2 cards perform better on small reads and writes. A 64 GB A2 card meets both requirements. (SanDisk A2 microSD 64GB on Amazon)
  • An SD card reader for writing the image from your computer. (USB microSD card reader on Amazon)
  • An Ethernet cable. Ethernet is required for installation; Wi-Fi can be configured afterwards, but Ethernet is more reliable and recommended.

The card reader is used only while writing the image; the other items stay with the install.

Pi 4 or Pi 5?

Both the Raspberry Pi 4 and the Raspberry Pi 5 are supported, with a minimum of 2 GB of RAM; boards with more memory also meet the requirement. The Pi 5 is the newer board. The choice has one practical consequence during installation: Home Assistant OS ships as separate builds for the Pi 4 and the Pi 5, and you select the matching build when you write the image. Note which board you have before you start.

Install Home Assistant OS step by step

Home Assistant OS (HAOS) is the recommended install type: an embedded, minimal operating system that includes Home Assistant Core and the Supervisor. The Supervisor keeps the system updated and supports apps (formerly called add-ons). The steps below run on your computer, with the SD card in the reader; the Pi is not connected yet.

  1. Install Raspberry Pi Imager from raspberrypi.com/software.
  2. Click Choose OS and select Other specific-purpose OS > Home automation > Home Assistant.
  3. Select the HAOS build that matches your board: the Raspberry Pi 5 build or the Raspberry Pi 4 build.
  4. Select the SD card. It will be overwritten, so confirm you have the right one.
  5. Click Next, then Write.
  6. When writing completes, click Finish and eject the card.

If you would rather not use Raspberry Pi Imager, download the HAOS image from the Home Assistant OS releases on GitHub and write it with Balena Etcher. The current release is HAOS 18.4 (released 27 October 2026), a bugfix and security release on kernel 6.18.58 that fixes the Realtek VLAN and RTL8761B Bluetooth regressions introduced in 18.3. Release downloads now include a SHA256SUMS file with a sigstore signature. The current image files are haos_rpi5-64-18.4.img.xz and haos_rpi4-64-18.4.img.xz; pick the one matching your board.

First boot and finding homeassistant.local

With the card written, three steps start the Pi:

  1. Insert the microSD card into the Pi.
  2. Plug in the Ethernet cable, on the same network as your computer, with internet access.
  3. Connect the power supply.

From a computer on the same network, browse to homeassistant.local. If that address does not load, try homeassistant.local:8123, homeassistant:8123, or http://<Pi IP>:8123, substituting the Pi's IP address. On a Pi 4 or Pi 5 the page should appear within a minute of connecting power. The documented setup involves no keyboard or monitor; everything after power-on happens in your browser.

If it doesn't come up

If the page has not appeared after five minutes, the installation documentation lists three remedies:

  • Reflash the card and try again.
  • Try a different microSD card.
  • Connect an HDMI monitor to the Pi to see the console.

Before reflashing, check two setup requirements: the Ethernet cable must run to the same network as your computer and have internet access, and the Pi must be on a proper power supply — phone chargers may not deliver full power, and computer USB ports must not be used. If homeassistant.local is the only address that fails, work through the alternatives listed above first.

SD card or SSD?

A microSD card is the documented installation path for Home Assistant OS on a Raspberry Pi, and it is the path this article follows. If you plan to boot from a USB SSD instead, one change in HAOS 18.4 is relevant: the release disables UAS for two USB adapters on the Raspberry Pi — the Argon ONE M.2 (ASMedia 174c:1156) and the UGREEN CM300 (ASM235CM) — to fix USB storage issues. That matters if your SSD sits behind one of those two adapters. For the card path, the A2 recommendation from the hardware list above applies.

HAOS vs Container on a Pi

Two install types are worth knowing about on a Pi:

  • Home Assistant OS (HAOS) — the recommended install type. An embedded, minimal OS that includes Core and the Supervisor; the Supervisor keeps the system updated and supports apps.
  • Home Assistant Container (Docker) — runs Home Assistant Core only. No Supervisor, no apps.

Both install types run the same Core; the current Core release is 2026.10.4 (24 October 2026). The difference in practice is the Supervisor and apps: a Container install has neither. This article assumes HAOS throughout.

What to do next

When the interface loads, onboarding takes you through three things: create your user, set your location, and review the devices Home Assistant has discovered. After onboarding, the Supervisor keeps the system updated.

FAQ

Can I install Home Assistant on a Raspberry Pi over Wi-Fi?

No. Ethernet is required for installation. Wi-Fi can be configured after Home Assistant is running, but Ethernet is more reliable and is the recommended connection.

Which Raspberry Pi do I need for Home Assistant?

A Raspberry Pi 4 or Raspberry Pi 5 with at least 2 GB of RAM. The Pi 5 is the newer board. During installation you select the HAOS build that matches your board.

What size microSD card do I need?

At least 32 GB, ideally with the Application Class 2 (A2) label. A2 cards perform better on small reads and writes. A card above the minimum, such as 64 GB, also qualifies.

Can I power the Raspberry Pi from a phone charger or a computer USB port?

A phone charger may not deliver full power, and computer USB ports must not be used. A proper power supply is part of the supported hardware list.
