01 · Home Assistant / Supervisor

Supervisor 2026.09.3 — app capability drops, API gating while starting

What happened: Tag 2026.09.3 published 2026-09-17T13:47:09Z — same Thursday as HAOS 18.3, but it never got its own rail while Core 2026.9.3 and the OS release filled the briefs. From the GitHub notes:

  • Feature flags to drop NET_RAW, plus MKNOD, AUDIT_WRITE, and SETFCAP, from app (add-on) containers
  • Block start / restart / rebuild / update APIs while Supervisor is not fully running
  • Don’t leave rejected AppArmor profile files in the store directory
  • Keep !secret references when persisting app options

Why it matters: Capability drops harden what apps can do on the host. API gating cuts racey start/update calls during Supervisor boot. If you run HAOS, this rides the usual Supervisor update channel — distinct from Monday’s OS 18.3 story.

Primary source
