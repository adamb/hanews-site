OpenWrt Firmware Selector: check if your router is supported and get the right image

HA News · 16 Nov 2026

Every OpenWrt project starts with two questions. Does OpenWrt run on my router? And which of these files do I download? Get the second one wrong and you have a very expensive paperweight, at least until you find a recovery guide.

The OpenWrt Firmware Selector answers both. Type your model, get the official images. Here is how to use it without drama.

Step 1: is my router supported?

Open firmware-selector.openwrt.org and type the model name exactly as printed on the label, for example "GL-A1300". If it shows up, you get a card with the model, its target (the chip family, such as ipq40xx/generic), the release and the download links.

If nothing shows up, there is no official build. Check the hardware revision too: vendors sell several versions under one name, and OpenWrt support is per revision. "v1" and "v2" can be completely different routers inside.

The odds are decent. OpenWrt's own device data, which we pulled this month, lists 2,187 devices with release builds. 2,153 of them have a build for the current release, 25.12.6.

Before you flash, open the model's page in the OpenWrt Table of Hardware (the selector links to it). It has the install steps for that exact device, plus any traps.

Step 2: pick a version

Take the default: the current stable release, 25.12.6 as of this writing (24.10.8 is the previous series). It gets the security fixes. Our OpenWrt 25.12 guide explains what's new.

Skip "snapshot". Those are nightly developer builds, and they don't include the LuCI web interface. Not what you want on the box your whole house depends on.

Handy trick: once you find your model, bookmark the URL. It looks like this one for the GL-A1300, with version, target and model baked in.

Step 3: factory or sysupgrade?

This is where people brick routers. The rule is simple:

Your router runs…DownloadFlash it with
The vendor's own firmwarefactory imageUsually the vendor's firmware-update page (check the device page)
OpenWrt alreadysysupgrade imageLuCI (System → Backup/Flash) or the sysupgrade command

Why two files? The factory image is wrapped in whatever format the vendor's updater expects. For the GL-A1300 on 25.12.6, that is glinet_gl-a1300-squashfs-factory.ubi. The upgrade file for a router already on OpenWrt is glinet_gl-a1300-squashfs-sysupgrade.bin.

Some devices have no factory image at all and are installed another way (a bootloader, TFTP or a vendor tool). The device page tells you. The project's factory vs sysupgrade guide has the full story.

Step 4: bake in your extras

Two features most people miss:

  • Customize installed packages. Add the packages you always install, like WireGuard, and the selector requests a custom build with them included. No reinstalling after every flash.
  • First-boot script. Paste a script that runs once on first boot to set things up. Handy if you run several identical routers.

Before you flash: the checklist

  • Model and hardware revision match the label.
  • Right image type: factory from vendor firmware, sysupgrade from OpenWrt.
  • Stable release, not snapshot.
  • You read the device page in the Table of Hardware.
  • If it's already on OpenWrt: back up your config first.

Then set a password and log in to LuCI, usually at http://192.168.1.1. Next stops: our OpenWrt guide and how to put smart-home gadgets on their own VLAN.
