18 September 2026

Home Assistant Core 2026.9.3 landed this morning — a patch release with Matter cover fixes for Shelly tilt-null, EnergyZero price regression repair, and backup rewrite encryption among the standouts. On the device rail, Hue Play gradient strip pro flipped to In stock on the UK storefront while the US page still says Coming soon. Aqara FP400 remains day-after worldwide ship.

01 · Home Assistant

Home Assistant Core 2026.9.3 — Matter Shelly covers, EnergyZero, backup rewrite

What happened: Core tag 2026.9.3 published 2026-09-18T12:11:05Z (author frenck), seven days after 2026.9.2. It is a patch release, not a feature drop. Standouts for local-stack readers from the GitHub body:

  • Fix Matter cover entity not created when tilt attribute is null for Shelly devices (#182042)
  • Fix EnergyZero market price regression (#181230)
  • Keep the known Bond host when zeroconf still announces it (#181975)
  • Encrypt and decrypt supervisor.tar in backup rewrites (#182220)
  • Require the IRK in the Private BLE Device config flow (#181969)
  • Make Nest climate turn_on idempotent (#182086)
  • Fix Alexa doorbell state report when return status is NO_CONTENT (#182209)
  • Bump reolink_aio to 0.21.17 (#182472)

Also in the notes: Spotify reauth crash when config entry data lacks id, Airthings BLE duplicate devices on incomplete read, IMAP custom data event template not reset when cleared, plus dependency bumps (holidays, pylutron, waterfurnace, aioamazondevices, hassil).

Why it matters: Shelly Matter blinds with a null tilt attribute were silently missing cover entities — this closes that hole. EnergyZero users get the market-price path fixed. Backup rewrite now encrypts/decrypts supervisor.tar. Upgrade from 2026.9.2 is the usual Supervisor / Core path.

Primary source
home-assistant/core 2026.9.3 (published 2026-09-18T12:11:05Z)
