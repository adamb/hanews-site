01 · Home Assistant

Home Assistant Core 2026.9.4 ships

What happened: Frenck tagged 2026.9.4 on Saturday (2026-09-27T09:51:05Z). Maintenance cut: Tuya fans turn off at 0% speed, Todoist timed calendar duration fix, ISEO Argo BLE discovery cleanup, HomematicIP Cloud PIN flow no longer advances on a rejected PIN, Z-Wave controller statistics key typo, HTTP security filter cost tracks request target length, plus Enphase / Xbox / OpenEVSE bumps.

Why it matters: Friday’s brief was still waiting on .4 — the patch cadence slipped a day into the weekend. Stable channel default is now 2026.9.4.

Primary source
home-assistant/core 2026.9.4; stable.json (default 2026.9.4)

02 · Matter & Thread

Thread Group approves Sub-GHz development

What happened: On 21 Sep the Thread Group Board of Directors approved work to extend Thread’s IP-based mesh to a Sub-GHz PHY. Official blog: commercial/industrial range and penetration use cases; a distinct brand name is promised in coming months. Spec, regional frequencies, and ship calendar are not published yet. Existing 2.4 GHz Thread hardware will not gain Sub-G via firmware alone.

Why it matters: Long-range Matter discussions finally have an official Thread track — still years of silicon and Matter accommodation away from shipping Matter-over-Sub-G devices, but the standards fork is no longer rumor.

Primary source
Thread Group blog, 21 Sep 2026; context Matter Alpha; Silicon Labs

03 · Matter

Matter 1.6.1 finalizes Groupcast; chime volume/mute

What happened: CSA released Matter 1.6.1, promoting Groupcast out of provisional status (recommended path for multi-device group commands) and adding optional speaker-endpoint volume/mute for doorbell chimes so sound can be silenced without killing visual alerts. No new device types — maintenance on existing categories.

Why it matters: Groupcast is the intended fix for the “popcorn” effect when HA helper groups poke Matter lights one-by-one. Home Assistant’s native Matter group work is on the OHF roadmap / Matter.js drafts — not a user-facing ship date yet.

Primary source
Matter Alpha on Matter 1.6.1 (CSA / Project CHIP)

04 · Devices / IKEA

IKEA TIMMERFLOTTE — test firmware 1.2.2 (Matter 1.5 / Thread 1.4)

What happened: IKEA published TIMMERFLOTTE firmware 1.2.2 to its Matter test network on 22 Sep. Notes: moves the E2314 sensor to Matter 1.5 and Thread 1.4, claims stability improvements, adds a serial-number attribute. Production channel remains 1.0.21.

Why it matters: Signal that IKEA is actively testing a newer Matter/Thread stack for this SKU — not a reason to reset working production units. HA Matter Server’s enable_test_net_dcl is the advanced path if you deliberately chase test builds.

Primary source
Matterhome, 26 Sep 2026; product IKEA TIMMERFLOTTE
